GIM-MED: ENFERMERÍA - PROYECTO INDEPENDIENTE
=======================================================
1. Extraiga TODO este ZIP en una carpeta propia.
2. Instale Python 3.9 o superior si aún no lo tiene (python.org).
3. En Windows, haga doble clic en INICIAR.bat. No use Go Live.
4. Abra http://localhost:5175/ en el navegador.
5. En el primer acceso cree su usuario y contraseña de este módulo.
6. Mantenga abierta la ventana del servidor mientras usa la web.

Archivos y carpetas:
- DOCUMENTACION_ESTRUCTURA.md y ESTRUCTURA.txt: árbol completo y descripción archivo por archivo.
- web/login.html, login.css, login.js: el mismo acceso visual de los tres módulos.
- web/interfaces/enfermeria/: interfaz original HTML, CSS, JavaScript y recursos.
- server.py: servidor local y rutas API de este módulo.
- schema.sql: estructura de la base de datos.
- data/gimmed.sqlite: base SQLite independiente que conserva los datos.
- data/session.key: clave necesaria para sesiones, guárdela junto a la base.
- config.py: rol y puerto 5175; cambie PORT si está ocupado.

PARA TRANSFERIR: cierre la ventana del servidor; copie la carpeta COMPLETA, incluido data/.
PARA RESPALDAR: copie data/gimmed.sqlite y data/session.key con el servidor cerrado.
Los tres módulos NO comparten usuarios, pacientes ni cambios entre sí automáticamente.
Para integrar datos después será necesario diseñar una sincronización o migración.
El acceso solo se expone en el mismo equipo (127.0.0.1).
No contiene datos personales reales ni contraseñas iniciales predefinidas.
