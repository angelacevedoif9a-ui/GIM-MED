Cómo se mide la actividad

El contador suma tiempo cuando detecta clics, escritura, desplazamiento o movimiento. Después de dos minutos sin interacción se considera pausa. Las horas extra se estiman al superar la jornada configurada para el empleado en Recursos Humanos.
